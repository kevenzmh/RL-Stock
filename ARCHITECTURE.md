## 系统组成

```

                              │
                              │ 调用
                              ▼
    ┌─────────────────────────────────────────────────────────┐

              │                           │

## 核心模块

┌──────────────────────────────────────────────────────────────┐
│                    realtime_data.py                          │
│                  (实时数据获取模块)                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌────────────────────┐                                     │
│  │ RealtimeDataFetcher │                                    │
│  └────────────────────┘                                     │
│           │                                                  │
│           ├─► get_latest_data()        # 单只股票           │
│           ├─► batch_get_latest_data()  # 批量获取           │
│           ├─► get_all_stocks()         # 股票列表           │
│           └─► close()                  # 关闭连接           │
│                                                              │
│  数据源: Baostock                                            │
│  特征: OHLCV + 估值指标 + 技术指标                            │
└──────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────┐
│                  model_inference.py                          │
│                   (模型推理引擎)                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────┐                                           │
│  │ModelInference│                                           │
│  └──────────────┘                                           │
│         │                                                    │
│         ├─► preprocess_data()         # 数据预处理          │
│         ├─► predict_single_stock()    # 单只预测            │
│         ├─► predict_batch()           # 批量预测            │
│         └─► get_top_stocks()          # 筛选Top N           │
│                                                              │
│  集成模块:                                                   │
│  ├─ StockTradingEnvEnhanced  (交易环境)                     │
│  ├─ add_all_technical_indicators (技术指标)                 │
│  └─ DataPreprocessor (数据预处理)                           │
│                                                              │
│  评分系统:                                                   │
│  ├─ 收益率 (50%)                                            │
│  ├─ 夏普比率 (30%)                                          │
│  └─ 回撤控制 (20%)                                          │
└──────────────────────────────────────────────────────────────┘

## 配置参数

┌─────────────────────────────────────────┐
│ 选股参数                                 │
├─────────────────────────────────────────┤
│ top_n            : 10    (返回数量)     │
│ stock_pool_size  : 100   (候选池大小)   │

│ days             : 60    (数据天数)     │

┌─────────────────────────────────────────┐
│ 评分权重                                 │
├─────────────────────────────────────────┤
│ 收益率   : 50%                          │

│ 回撤控制 : 20%                          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 推荐阈值                                 │
├─────────────────────────────────────────┤
│ 强烈推荐 : score>=70 && return>5%       │
│ 推荐     : score>=50 && return>0        │
│ 中性     : score>=30                    │
│ 不推荐   : score<30                     │
└─────────────────────────────────────────┘


## 性能指标

┌──────────────────────────────────────────┐
│ 时间复杂度                                │
├──────────────────────────────────────────┤
│ 获取数据 : O(n)  n=股票数量              │
│ 技术指标 : O(n*m) m=数据天数             │
│ 模型推理 : O(n*m*k) k=交易步数           │
│ 总体     : O(n*m*k)                      │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│ 空间复杂度                                │
├──────────────────────────────────────────┤
│ 数据存储 : O(n*m*f) f=特征数            │
│ 模型参数 : O(p) p=神经网络参数          │
│ 总体     : O(n*m*f + p)                  │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│ 实测性能 (参考)                           │
├──────────────────────────────────────────┤
│ pool=100, days=60                        │
│ ├─ 时间: 5-10分钟                        │
│ ├─ 内存: ~800MB                          │
│ └─ 成功率: ~95%                          │
└──────────────────────────────────────────┘
